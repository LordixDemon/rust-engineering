# Project languages

[English](#english) | [Русский](#russian)

<a id="english"></a>

## English

Keep English and Russian in the same README, documentation and skill files.
Place the complete English section first and the complete Russian section second,
with in-file language links in that order. Do not create separate `.ru.md` files.
Update both sections when their shared content changes.
Keep code identifiers, CLI options, JSON keys and source citations stable.

---

<a id="russian"></a>

## Русский

Храните английскую и русскую версии README, документации и инструкций скилла
в одном файле. Сначала размещайте полный английский раздел, затем полный русский;
ссылки на языки ведут в разделы этого файла и идут в том же порядке.
Не создавайте отдельные файлы `.ru.md`. При изменении общего содержания обновляйте
оба раздела. Идентификаторы кода, параметры CLI, ключи JSON и ссылки на источники
сохраняйте без изменения.
